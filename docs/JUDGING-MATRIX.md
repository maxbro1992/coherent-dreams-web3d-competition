# Judging alignment

| Official criterion | Weight | Evidence in Coherent Dreams |
|---|---:|---|
| Innovation and originality | 30% | A single browser experience joins immersive phase-field terrain, transparent local ML, grounded region ranking, and side-by-side scientific provenance. |
| Technical excellence | 25% | Typed-array pipeline, Worker isolation, deterministic analysis, indexed geometry, WebGPU renderer with fallback, responsive controls, reduced-motion support, and a static production build. |
| AI integration | 20% | Four-feature unsupervised model, semantic cluster mapping, global morphology metrics, three objective-specific rankers, relative assignment certainty, and evidence for every finding. |
| User experience | 15% | The interactive field fills the first viewport. Three visual modes, camera presets, physical scale, keyboard shortcuts, live status, readable panels, and provenance/model dialogs support exploration. |
| Impact and scalability | 10% | The zero-backend architecture can accept other scalar fields and suits private, classroom, secure, or low-connectivity settings. Analysis and rendering resolution are explicitly bounded for integrated GPUs. |

## Demonstration priorities

1. Establish the immersive terrain within the first 20 seconds.
2. Show that changing visual mode does not change source measurements.
3. Demonstrate one rare-region result and one interface result with evidence chips.
4. Open provenance and model-card dialogs to make transparency visible.
5. End with the cross-domain extension pattern and zero-upload privacy benefit.
