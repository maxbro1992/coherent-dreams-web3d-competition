# Demo video script and shot list

**Rendered duration:** 4:50  
**Official allowed duration:** 3–5 minutes  
**Language:** English  
**Delivery:** 1920 × 1080, 30 fps, H.264 video, AAC stereo audio, external English SRT captions

The rendered video follows this script exactly. Narration uses the local Microsoft Zira system voice; it contains no licensed music or third-party audio.

## 0:00–0:16 — Coherent Dreams

**Shot:** branded title card derived from the project artwork.

**Narration:**

“Coherent Dreams is an AI morphology explorer built for the open web. It turns a deterministic scientific field into an interactive landscape, then helps a visitor find and understand the structures that deserve attention.”

## 0:16–0:54 — The field becomes a place

**Shot:** full perspective view in Phase field mode.

**Narration:**

“Scientific simulations often finish as flat figures. Coherent Dreams turns one Cahn-Hilliard phase field into a place we can explore. This terrain represents phase separation across an imagined 2.56 micrometre nickel-aluminum film. Every peak and valley comes from the unchanged scalar source. The browser builds a mesh of 25,600 vertices and more than 50,000 triangles. Three.js selects WebGPU on capable devices and falls back to WebGL 2 elsewhere, so the same experience remains accessible without specialist software.”

## 0:54–1:36 — Transparent provenance

**Shot:** Source panel with the grayscale field and artwork side by side.

**Narration:**

“The source view keeps scientific data and artistic interpretation explicit. On the left is the unmodified simulation field. On the right is the human-directed Coherent Dreams artwork derived from that field. The artwork supplies the visual palette, while the grayscale source alone drives geometry, features, and measurements. The random seed, grid size, integration steps, parameters, and imagined physical scale are archived with the project. This separation is deliberate: a compelling image can invite exploration without being mistaken for evidence. Reviewers can reproduce the source and trace every displayed measurement back to it.”

## 1:36–2:23 — Browser-native AI

**Shot:** AI clusters mode with the rare morphology objective and ranked evidence.

**Narration:**

“Analysis happens locally in a Web Worker, so the field never needs to leave the device. Each sample becomes a four-feature vector: composition, gradient magnitude, absolute Laplacian, and local variance. A deterministic farthest-point initialization followed by k-means discovers four morphology regimes. The region scout can search for rare signatures, active interfaces, or representative phase interiors. Here it identifies an unusual nickel-rich patch and exposes the gradient, curvature, and rarity evidence behind the rank. Cluster colors show the learned partition, while the right panel explains why a specific region was selected. This is machine learning used as a transparent guide to attention, not as a hidden oracle.”

## 2:23–3:10 — From overview to evidence

**Shot:** Interfaces mode, macro camera, selected local region.

**Narration:**

“Interface mode suppresses phase interiors and emphasizes transition boundaries. The scout ranks eight spatially separated regions, which prevents one energetic neighborhood from filling the entire recommendation list. Focus camera moves directly to the selected patch. Relief and phase threshold can be changed for visual inspection while the underlying source and reported metrics remain fixed. The dashboard summarizes phase balance, interface density, characteristic domain scale, structure-tensor anisotropy, normalized entropy, and connected components. Each recommendation uses measured percentiles and a short grounded explanation. The visitor can move from a global structure to one local claim, see the evidence, and return to the full field without breaking spatial context.”

## 3:10–3:53 — Method and limits

**Shot:** Method panel with the three pipeline stages and scientific scope.

**Narration:**

“The model card explains the pipeline in plain language. Feature extraction, clustering, connected-component analysis, and ranking are deterministic and inspectable. Recommendations come from fixed templates grounded in the measured feature values. There is no remote model call, no prompt injection surface, and no field upload. The app also states its limits. This simulated field is not calibrated microscopy. The physical scale is illustrative. Cluster names are descriptive rather than validated material labels. The interface is intended for exploration and communication, not for process control, diagnosis, or materials decisions. Making those limits visible is part of the design, because interpretability also means knowing where an inference stops.”

## 3:53–4:34 — Why Web3D

**Shot:** elevated field overview and complete dashboard.

**Narration:**

“Web3D makes relationships spatial, interactive, and shareable through a link. The local pipeline keeps latency predictable and allows sensitive fields to remain private. The same architecture can accept microscopy, climate, medical imaging, manufacturing, fluid simulation, or other scalar data. New feature adapters and explanation templates can extend the scout without replacing the renderer or the interaction model. Keyboard controls, reduced-motion support, responsive panels, and a WebGL fallback widen access. Coherent Dreams demonstrates that an immersive scientific experience can use AI to guide attention while keeping its source, evidence, assumptions, and limits in view.”

## 4:34–4:50 — End card

**Shot:** branded end card.

**Narration:**

“Coherent Dreams turns one reproducible field into an explorable world, and one machine-learned ranking into evidence a person can inspect. Thank you for exploring it.”
